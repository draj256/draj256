## Ranu.js

### A TypeScript-first full-stack web framework

**Ranu.js** is my primary open-source project and long-term framework initiative.

The goal is to build a modern full-stack foundation for developers who want a productive TypeScript development experience across application architecture, rendering, routing, tooling, and deployment.

**Project:** [github.com/hoslift/ranu.js](https://github.com/hoslift/ranu.js)

**Website:** [ranu.js.org](https://ranu.js.org)

```bash
npx create-ranujs@latest my-app
```

Ranu.js is currently in **public Alpha** and actively evolving.
